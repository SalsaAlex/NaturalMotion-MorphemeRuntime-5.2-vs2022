# GameManagement documentation

This serves more as a base/example for implementing morpheme characters into other environments or engines. 

There are 3 versions of this game manager:
- **No Physics** : Minimal version. Name is self explanatory, does not include any physics.
- **PhysX3** : Includes support for the PhysX3 physics engine.
- **Euphoria** : Includes support for the PhysX3 physics engine and Euphoria simulated characters.
